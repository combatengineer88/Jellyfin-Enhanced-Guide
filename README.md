# Jellyfin Enhanced Guide

Target: Jellyfin Server 12.1, Windows, ErsatzTV XMLTV schedules.

Development preview: the initial browser-side prototype enhances the existing guide without replacing playback or recording actions. It is not yet a compiled Jellyfin server plugin.

Artwork priority: movie primary image; TV season primary image; series primary image; guide program artwork. Matching must respect the signed-in user's library permissions.

Planned modes: Poster (default), Classic, Cinematic, Compact. Server plugin packaging and injection integration require validation against Jellyfin 12.1.
